# Aether-GUI v0.17.1

A focused patch for the IP Changer panel resizing issue after starting Tor.

## Fixed

- Fixed the IP Changer panel expanding beyond the app window after Tor starts producing log output. The panel now stays constrained to the available window width when resizing smaller.
- Long Tor log messages, including unbroken relay identifiers and paths, now wrap within the log viewer instead of forcing it wider. Message text and line breaks are preserved.
- Applied the scroll-container sizing correction to the shared panel dialog, also used by Advanced, Presets, History, and Settings.

## Unchanged

- The bundled Aether engine remains **2.0.0**.
- This release changes UI layout only; Tor startup, IP rotation, proxy settings, and tunnel behavior are unchanged.
